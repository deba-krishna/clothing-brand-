## Deployment Instructions

### Quick Start (Vercel)

1. Push code to GitHub
   ```bash
   git push origin main
   ```

2. Connect to Vercel
   - Visit vercel.com
   - Import your GitHub repository
   - Click Deploy

3. Verify live
   - Visit your Vercel URL
   - Test all functionality
   - Confirm responsive design

### Local Testing

1. Start local server
   ```bash
   python3 -m http.server 8000
   ```

2. Open browser
   ```
   http://localhost:8000
   ```

3. Test features
   - Add items to cart
   - Remove items
   - Update quantities
   - Check calculations
