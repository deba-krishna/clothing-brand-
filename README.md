# 🖤 NOIR — Premium Clothing Brand Website

A modern, responsive, and premium clothing brand website built using **HTML**, **CSS**, and **JavaScript**.

NOIR is designed with a luxury-inspired aesthetic, clean layouts, smooth animations, and a seamless shopping experience. This project showcases modern frontend development practices and serves as both a portfolio project and the foundation for a complete e-commerce platform.
